## The Repository
This repository is where the **LS Code** development occurs.
Pull requests and issues are managed via Github.

## LS Code
Lightweight Studio Code is a rewrite of [Visual Studio Code](code.visualstudio.com) built on top of Tauri, instead of Electron.
Visual Studio Code is famous for its high memory usage. There are many alternatives, such as [Neovim](https://neovim.io/), but VS Code's high featured marketplace makes it hard to switch. This project aims to be the closest as possible to VS Code, which includes extreme compatibility with already existent extensions.

## Contributing
There are many ways for you to contribute to this project:
* Opening a pull request
* Filing an issue
* Creating feature requests

### Issues
While filing an issue, the most information you can give us, the better. Include LS Code's version, OS, and how to replicate the bug, and we'll do our best to fix it.
