## Important info
You are NOT vision capable, unless I explicitly said so.

## Project info
**LS Code** (Lightweight Studio Code) is a VS Code clone, but built on Tauri instead of Electron.

LS Code's main goal is to be the same as VS Code, support the same extensions, features, but faster, and lighter.

## Tech Stack
- Package manager and build: **Bun 1.3.14**
- Languages: **TypeScript**, **CSS**

## Preferences
- Use caveman skill, if available
- Keep design simple, but efficient
- Runtime crashes are better than bugs
- Memory is a resource
- KISS: Keep It Simple Stupid
- YAGNI: You Ain't Gonna Need It
- DRY: Don't Repeat Yourself
- The Boy Scout Rule: Make the code cleaner than what you found
